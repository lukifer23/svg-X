# SVG-X engineering audit · November 20, 2026

The starting revision was `63229f4`. The hosted validation, browser, unsigned
package, and batch performance jobs passed for that revision. npm reported zero
known advisories before and after this pass. GitHub listed zero open pull
requests. The Dependabot alerts API returned HTTP 401, so the repository alert
count requires a maintainer view. Electron, Vitest, and lucide-react were
updated in the frozen lockfile. TypeScript remains on the supported linting
toolchain version.

## Changes in this pass

- Desktop batch jobs align their automatic decode limits with single-image
  settings at 1000 or 2000 pixels on the longest side. An explicit batch resize
  still takes precedence. Sharp resizes before RGBA crosses IPC.
- Cancelling a batch keeps controls locked until in-flight jobs settle. A
  pending-file run preserves completed outputs and failures, and an empty input
  folder clears the previous queue. A native write already in progress can
  complete during cancellation.
- Directory grants resolve to canonical paths. Batch reads require a regular
  file in the granted directory, and privileged IPC requires the top frame.
- Color accepts up to sixteen palette entries. The default remains eight.
  A flat artwork regression fixture checks that all sixteen requested regions
  survive quantization and tracing.
- Centerline thinning treats the area outside the raster as background and
  avoids allocating a neighbor array for each foreground pixel. Path
  simplification uses an explicit work stack and avoids recursive array copies.

## Remaining work in priority order

1. **Color boundary fidelity.** The label map is disjoint, but neighboring rings
   are simplified and fitted independently. Fit a shared edge once, reverse it
   for the adjoining region, and measure seams and overlaps at multiple scales.
   Apply speck removal to labeled components before contour extraction so small
   features and holes are handled consistently on both sides of an edge.
2. **Trace quality.** Add measured results for noisy scans, cropped strokes,
   close parallel strokes, and varied junctions. Measure endpoint displacement,
   junction and cycle counts, and centerline distance before adding optional
   spur removal. Keep the B&W Potrace raster-compatibility gate.
3. **Native batch coverage and usability.** Exercise real directory selection,
   corrupt input, collision, cancel while decoding, resume, and retry in the
   packaged app. The Worker benchmark omits filesystem and IPC costs. Add a
   directory-to-directory benchmark with mixed dimensions and formats. Measure
   wall time and process RSS alongside browser heap. Add per-file export format
   selection and a saved failure report after the native workflow is covered.
4. **Decode and optimization responsiveness.** Native decodes already in flight
   settle before cancellation completes. Browser decode and optional SVGO need
   separate profiling and cancellation coverage. Browser canvas and Sharp use
   different resamplers, so matching size limits alone cannot guarantee
   pixel-identical output. Test first-frame animation behavior, EXIF, alpha,
   and color profiles before changing either decoder.
5. **Security and distribution.** Verify Dependabot alerts with an account that
   has repository security access. The canonical-path check narrows ordinary
   symlink access but does not eliminate filesystem races during path-based
   reads. Test grant lifetimes, atomic publication on supported filesystems,
   LAN on real IPv4/IPv6 hosts, installer signing and notarization, and HEIC on
   each target codec build. Issue #37 remains open until a color binary ships.
